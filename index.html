Apollonian Twist

逐层拆解一个 WebGPU 光线步进分形着色器:折叠、反演、第四维扭转、距离场、着色。每一步都可以动手调。

拖动旋转,滚轮缩放。这就是原着色器的效果:一个主团簇和两个小卫星团簇,在 4D 空间里缓慢翻滚,我们看到的是它们的 3D 截面。

需要支持 WebGPU 的浏览器(新版 Chrome / Edge / Safari)。3D 视窗比较吃显卡,离开视口时会自动暂停;卡顿时可以把“分辨率”调低。

0 · 总览:一帧画面是怎么来的

这是一个典型的 距离场 + 光线步进(sphere tracing)着色器。整个画面只有一个全屏三角形,所有几何都在片元着色器里用数学“算”出来。数据流如下:

fragment_main
像素 → 光线方向→ trace_scene
沿光线步进→ map_scene
3 个团簇取最近→ cluster
旋转 / 漂移 / 抬到 4D→ apollian
折叠 + 反演 ×16→ render_scene
法线 + 光照 + 配色
  1. 折叠:把空间卷进一个盒子
  2. 反演:球面内外翻转
  3. 迭代:Apollonian 结构与距离估计
  4. 第四维:名字里的 “Twist”
  5. 团簇、包围球与卫星
  6. 光线步进
  7. 法线与着色
  8. 参数速查

1 · 折叠:把空间卷进一个盒子

apollian() 每一轮的第一步:

p = -1.0 + 2.0 * fract(0.5 * p + 0.5);

它对每个分量做一个周期为 2 的锯齿波,把任意点平移回 [-1, 1]⁴ 这个盒子里。效果等价于:整个空间被切成 2×2 的格子,每个格子里放着完全相同的一份内容。所以只要在中间这个盒子里定义好形状,它就自动无限重复。注意这里是平移(fract),不是镜像(abs),所以每个格子是同向复制。

拖动粉色点。青色点是它折叠后的位置,一定落在蓝框里。黄色图案在每个格子里都一样:对折叠后的坐标来说,它们是同一个东西。

2 · 反演:球面内外翻转

第二步是球反演,半径为 √s:

let r2 = max(dot(p, p), 1.0e-5);
let k = s / r2;      // s = 1.24
p = p * k;
scale = scale * k;   // 记录累计的缩放倍数

反演把球内的点翻到球外、球外的点翻到球内,并且有个关键性质:圆(球)映成圆(球),穿过原点的圆会变成直线,反之亦然。靠近原点的小东西会被放大成很大的东西,这就是 k 会远大于 1、scale 不断变大的原因。

拖动白色句柄。橙色圆 → 金色像;紫色直线 → 粉色像(一个穿过原点的圆)。蓝色虚线是反演球。背景暗蓝的弯曲网格是直角网格的反演像。试着把橙色圆拖到原点附近,看它被放得多大。

3 · 迭代:Apollonian 结构与距离估计

把“折叠 + 反演”重复 16 次,就得到了 Apollonian 类型的分形(和 Apollonian 垫片、Kleinian 群同一家族:都是由反演生成的)。直觉上:折叠把空间排成一排排重复的“球孔”,反演又把每个孔内部的整个无穷格子塞进一个小球里,于是大球里套着无数小球,小球里再套更小的球。

那表面在哪?看函数最后一行:

return FoldResult(abs(p.y) / scale, trap, detail);

迭代结束时的点 p 处在“最深一层”的坐标系里,在那里我们只放了一个最简单的形状:平面 y = 0,它的距离就是 |p.y|。因为反演会把长度放大 k 倍,回到原始空间时要除以累计的 scale,这样得到的仍然是一个(保守的)距离估计。于是:一个平面,经过所有层的折叠和反演之后,变成了一张布满圆孔的分形曲面。

下面是这个距离场在 z 截面上的样子(橙 = 外部,蓝 = 内部,白线 = 表面,条纹是等距线)。把迭代次数从 0 拖到 16:0 次时就是一条直线 y=0,1 次后开始出现圆,之后每多一次,圆里就多一层圆。

4 · 第四维:名字里的 “Twist”

  
注意 apollian() 接收的是 vec4。在 cluster() 里,3D 点被抬到 4D:

  
var pp = vec4<f32>(q + off, 0.0);
pp.w = 0.055 * (1.0 - tanh_approx(0.82 * length(pp.xyz)));   // 中心鼓起的“第四维高度”
pp.yz = rotate2(pp.yz, tm * 0.52 + 0.14 * phase);
pp.xz = rotate2(pp.xz, tm * 0.35 - 0.10 * phase);
pp.xw = rotate2(pp.xw, -tm * 0.46 + 0.38 * phase);              // 混入 w 的旋转
pp.yw = rotate2(pp.yw,  tm * 0.64 - 0.22 * phase);

  
分形本身是 4D 的,我们看到的是一个 3D 截面。w 不是常数,而是一个随半径衰减的“鼓包”:中心处 w≈0.055,边缘趋向 0。于是不同半径处其实在切 4D 分形的不同“高度”。再加上 xw、yw 平面上的旋转,这个截面会随时间在 4D 里转动,3D 里看到的形状就会扭曲、开合、流动,而不是简单地刚体旋转。这就是 “twist”。

5 · 团簇、包围球与卫星

  
包围球。因为最深一层是一个无限大的平面,如果直接用,画面里会出现一张无限延伸的平板。原代码注释也说了这一点,解决办法是和一个球求交:

  
return MapData(max(fractal, length(p) - radius), fold.trap, fold.detail);

  
max(a, b) 是距离场里的“交集”。下面把“包围球”关掉试试,就能看到那张平板(被 scene_gate 的半径 3 截断)。

  
卫星团簇。map_scene() 一共调用三次 cluster():一个主团簇,两个缩小的副本。副本用的是标准的“局部坐标缩放”技巧:

  
let sat1Local = (p - AP_SAT1_CENTER) / AP_SAT1_SCALE;     // 进入卫星的局部坐标
var sat1 = cluster(sat1Local, time, 1.7, 0.0040, 0.92);
sat1.dist = sat1.dist * AP_SAT1_SCALE;                     // 距离再乘回来

  
每个卫星有不同的 phase(1.7 和 −2.0),所以动画节奏错开。为了省算力,只有当采样点离卫星够近(sat1Gate < AP_SAT1_EVAL_MARGIN)时才去算它的分形,远处直接跳过。三者取 min 就是“并集”,同时把对应的 trap 和 detail 一起带出来,供着色使用。

  
运动。cluster() 开头的三个 rotate2 让团簇整体缓慢翻滚;off 用三个频率为 √3、√1.5、√2 的正弦让它在 4D 里漂移。频率两两不成有理比,所以运动永远不会精确重复。

  

    
    
    

  


  
  
6 · 光线步进

  
有了距离场 map_scene(p)(“p 离最近表面至少有多远”),渲染就是 sphere tracing:沿光线每次前进这么远,一定不会穿过表面。离表面越近步子越小,直到距离小于阈值就算命中。

  
let gate = scene_gate(samplePos);              // 离半径 3 的大球有多远
if (gate > AP_GATE_MARGIN) {                    // 还在大球外:不用算分形,直接大步走
  t = t + clamp(gate * 0.76, 0.015, 0.22);
  continue;
}
let hit = map_scene(samplePos, time);
let precis = 0.00012 + 0.00009 * t;            // 越远的地方允许越粗的精度
if (hit.dist < precis) { return TraceResult(true, t, trap); }
t = t + clamp(hit.dist * 0.82, 0.0015, 0.15);   // 乘 0.82 是“保守系数”

  
分形的距离估计并不精确(/scale 只是近似),所以每步只走 82%,并限制最大步长 0.15,防止跨过细小的结构;最小步长 0.0015 防止在擦边处原地打转。下面在 2D 截面上演示,绿色圆就是每一步的“安全半径”。

  

    

      

      

        

        

        
拖动白点(相机)和黄点(方向)。把步长系数调到 1 以上,可能会出现“穿模”:直接跳过薄片,命中了后面的东西。调小则更安全但步数暴增。在下面第 7 节的 3D 视窗里选“步进次数热图”,可以看到真实画面里每个像素用了多少步:物体轮廓附近的擦边光线最贵。

      

    

  


  
  
7 · 法线与着色

  
法线用“四面体”有限差分:只采样 4 个点(而不是中心差分的 6 个),用的是更便宜的 map_distance(9 次迭代)。eps 随距离增大,远处的细节自然被平滑掉,减少噪点。

  
let e = vec2(eps, -eps);
normalize(e.xyy * map(pos + e.xyy) + e.yyx * map(pos + e.yyx)
        + e.yxy * map(pos + e.yxy) + e.xxx * map(pos + e.xxx));

  
轨道陷阱(orbit trap)。迭代过程中记下 trap = min(|x|, |y|, |z|, r²)。其中 r² 的最小值说明这个点曾经多么接近某一层的反演中心,也就是它处在多深的“缝隙”里,被当成环境光遮蔽(AO)来用;trap.x / trap.y 很小时意味着点贴近某个坐标平面,用 exp(-13·trap.x) 做出金色的发光脉络。

  
detail 综合了两件事:在第几轮迭代时离反演中心很近(越晚越大),以及累计缩放 log2(scale)/22。值越大表示越“精细”的结构。配色是三段式:detail 低 → 深绿,中 → 草绿,高 → 金色再到暖白;再叠加主光、补光、边缘光,最后乘一个距离雾 exp(-0.055 t) 并做对比度曲线和 sqrt(近似 gamma)。

8 · 参数速查

  

    
常量 / 位置值作用

    
apollian(pp, s)s = 1.24反演强度(半径 √s)。越大孔越大、结构越稀疏;接近 1 时更密。

    
AP_APOLLIAN_ITERS16折叠 + 反演轮数,决定能看到多少层细节。

    
zoom4.10进入分形前把坐标缩小 4.1 倍,相当于从分形里截取中心一小块。

    
pp.w 系数0.055 / 0.82第四维鼓包的高度和衰减速度。

    
thickness0.0048 / 0.0040 / 0.0038从距离里减去,把零厚度的曲面加厚成薄壳。

    
radius1.08 / 0.92 / 0.88各团簇包围球半径,裁掉无限平面。

    
AP_SAT1/2_CENTER, SCALE(1.05,0.28,−0.22)×0.34;(−0.90,−0.42,0.30)×0.29两个卫星的位置和大小。

    
AP_MAX_TRACE_STEPS160每条光线最多步数。

    
AP_MAX_DISTANCE14最远行进距离。

    
scene_gate / AP_GATE_MARGIN半径 3 / 0.36大包围球:球外只做廉价的大步前进。

    
步长clamp(d·0.82, 0.0015, 0.15)保守步进,防穿模。

    
2.35 * forward焦距视角约 24°,较长焦,压缩透视感。
